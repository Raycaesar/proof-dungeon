# 证明迷宫（Proof Dungeon）简体中文分支

本项目基于 [Takayuki Kihara 的 Proof Dungeon](https://github.com/kihara-logic/proof-dungeon)，进行中文本地化和文件结构整理。保留原有 22 层、119 关、证明检查器、反模型机制与存档格式。

## 如何运行

解压后，直接在浏览器中打开仓库根目录的 `index.html`，或在根目录使用 `python -m http.server 8000` 并访问 `http://localhost:8000/`。无需 npm 安装、打包器或后端。部分网络字体和 MathJax 依赖联网加载。

## 当前本地化状态（第十批）

- **简体中文为默认语言**，右上角语言按钮支持「简中 → 日本語 → EN → 简中」循环切换。
- 已翻译 **3,202 / 3,202 条索引文本（100%）**。第十批又补齐了 11 个未索引的书库正文小节，使原始双语正文的 19 个小节全部拥有中文版本；同时修复中文动态文本可能误回退英文的问题。
- 此前各批的主界面、关卡叙事和书库译文继续保留；详细翻译范围参见 `docs/TRANSLATION_STATUS.zh-CN.md` 和 `docs/TRANSLATION_BATCH09.md`。
- 所有索引条目与已识别的 19 个非索引日英书库正文小节均有中文译文。完整浏览器交互与 119 关实际页面仍需逐关复核；详情见 `docs/LOCALIZATION_AUDIT_BATCH10.zh-CN.md`。
- 日文与英文保存在 `src/i18n/catalog.js`，任何中文翻译都没有覆盖原文。原有 22 层、119 关、证明检查器与存档结构未改变。

## 目录说明

```text
proof-dungeon/
├── index.html                 # 纯页面结构与静态脚本/样式引用
├── src/
│   ├── css/app.css            # 从 HTML 分离的全部样式
│   ├── js/app.js              # 游戏引擎、关卡、书库与 UI，保持现有运行顺序
│   ├── i18n/catalog.js        # 原版 3202 条日英文本索引
│   ├── i18n/zh-CN.js          # 中文译文覆盖层（索引 → 译文）
│   ├── i18n/books.zh-CN.js    # 非索引书库长文的逐节中文译文
│   ├── data/                  # 后续结构化关卡/世界/图书数据
│   └── modules/               # 后续拆分模型、公式解析、证明检查等模块
├── assets/
│   ├── images/               # 后续图片资源
│   └── audio/                # 后续音效
├── docs/                     # 扩展设计与说明
├── scripts/                  # 工具脚本
└── tests/                    # 回归和一致性检查
```

目前的 `app.js` 仍保留原来的单个游戏闭包，确保原有全局词法作用域和调用次序不变。后续可逐步拆分出证明引擎、关卡数据、故事与书库；不建议在缺少回归测试时一次性把几千行文件改成互相依赖的 ES 模块。

## 翻译开发

在 `src/i18n/zh-CN.js` 中按原索引补充条目，例如：

```js
25: "假设之室",
```

翻译时必须保持诸如 `⟦0⟧`、`⟦1⟧` 的占位符不变，保留 HTML 片段标签，不要改动公式、证明规则、关卡 ID。建议后续对未索引正文、书库内容和 119 关实际页面进行校对与回归测试。
